# M0-A01: Godot toolchain and device baseline

## 1. Mục tiêu
Khởi tạo project Godot 4.x baseline, cấu hình renderer, tỷ lệ khung hình, thiết bị mục tiêu và cấu trúc thư mục game cơ sở.

## 2. Tiêu chí nghiệm thu (Acceptance Criteria)
- [ ] Khởi tạo `game/project.godot` hợp lệ với Godot 4.x.
- [ ] Cấu hình viewport portrait chuẩn mobile theo GDD.
- [ ] Thiết lập baseline chạy offline và không phụ thuộc dịch vụ ngoài.
- [ ] Khóa Godot minor version, renderer và export templates dùng cho M0.
- [ ] Ghi rõ Android/iPhone mục tiêu, phiên bản OS, ngân sách RAM/VRAM và môi trường macOS/Xcode trong `toolchain-baseline.md`.
- [ ] Import headless thành công và ghi kết quả build/export smoke Android/iOS; nếu chưa có máy macOS/Xcode thì package phải báo blocked, không được handoff như đã đạt.
