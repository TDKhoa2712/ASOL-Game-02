# M0-A01: Godot toolchain and editor baseline

## 1. Mục tiêu
Khởi tạo project Godot 4.7.2 baseline, cấu hình renderer, tỷ lệ khung hình, export host và cấu trúc thư mục game cơ sở để phát triển trực tiếp trong Godot Editor.

## 2. Tiêu chí nghiệm thu (Acceptance Criteria)
- [ ] `game/project.godot` tải được bằng Godot 4.7.2 đã khóa.
- [ ] Bootstrap Editor/headless khởi động sạch với cấu hình portrait và renderer `mobile`.
- [ ] Probe tự động kiểm tra project feature pin, viewport, renderer, ETC2/ASTC và export presets.
- [ ] Android host export tạo được APK debug đã ký; báo cáo baseline định danh mọi phần device/iOS chưa đo và không tuyên bố các phần đó đã pass.
