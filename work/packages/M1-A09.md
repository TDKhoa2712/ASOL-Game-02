# M1-A09: Home screen layout correction

## 1. Mục tiêu và bối cảnh

Khắc phục lỗi các control trên Home bị chồng lên nhau do các node nội dung đang nằm ngoài `VBoxContainer/Stack`.

## 2. Tiêu chí nghiệm thu

- [ ] Title, CurrentLevelLabel, PlayButton, HelpButton, SettingsButton và ProgressHint đều là con trực tiếp của `SafeArea/Content/Stack`.
- [ ] Stack giữ khoảng cách dọc nhất quán và không còn control Home nằm trực tiếp dưới `Content` ngoài Stack.
- [ ] Các nhãn, nút, safe area và touch target hiện có được giữ nguyên.
- [ ] Test headless xác nhận hierarchy layout và các màn UI còn lại không bị ảnh hưởng.

## 3. Lệnh kiểm chứng

- `godot --headless --path game --script res://tests/run_ui_shell_tests.gd` (godot_home_layout).

## 4. Rủi ro và trọng tâm review

Đây là sửa layout scene, không thay đổi flow, gameplay, save hoặc dữ liệu campaign. Kích thước thực tế trên thiết bị vẫn thuộc device QA/M1-GATE.
