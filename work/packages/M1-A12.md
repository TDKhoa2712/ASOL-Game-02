# M1-A12: Defer gameplay result transition until input completes

## 1. Mục tiêu

Không giải phóng `BoardView` trong khi `_gui_input()` vẫn đang xử lý thao tác kết thúc level. Việc chuyển sang màn thắng/thua phải xảy ra sau vòng input hiện tại.

## 2. Tiêu chí nghiệm thu

- [ ] Sau nước thắng/thua cuối cùng, Puzzle vẫn hợp lệ trong cùng vòng xử lý input.
- [ ] Ở frame kế tiếp, Bootstrap hiển thị đúng `result_win` hoặc `result_fail`.
- [ ] Không còn lỗi gọi `accept_event()` trên instance đã bị giải phóng.
- [ ] Không phá các kiểm thử runtime, UI flow, UI shell và level validator hiện có.

## 3. Lệnh kiểm chứng

- `godot --headless --path game --script res://tests/run_mvp_runtime_tests.gd`.

## 4. Phạm vi

Chỉ điều chỉnh thời điểm dispatch kết quả trong Bootstrap và bổ sung regression test. Không đổi luật thắng/thua, schema save, layout kết quả hoặc asset.
