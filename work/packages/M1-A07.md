# M1-A07: MVP UI flow shell

## 1. Mục tiêu và bối cảnh

Nối các màn UI đã có thành một luồng MVP có thể chạy và kiểm thử độc lập: Home → Puzzle → Result Win/Fail → Next/Retry/Home, cùng Help và Settings. Luồng dùng ID level của campaign M1 nhưng chưa tích hợp save, Hint, tutorial hoặc gameplay runtime đầy đủ.

## 2. Tiêu chí nghiệm thu

- [ ] Bootstrap hiển thị Home khi khởi động và có thể chuyển tới Puzzle, Help, Settings, Result Win và Result Fail.
- [ ] Next chuyển đúng level kế tiếp; Retry giữ nguyên level; Home quay về Home; thắng level cuối quay về Home.
- [ ] Route hợp lệ và route không hợp lệ được kiểm thử headless; trạng thái không bị đổi bởi action không hợp lệ.
- [ ] Tái sử dụng scene UI M1-A05, giữ bố cục safe-area và kích thước touch target hiện có.
- [ ] Handoff ghi rõ phần placeholder và phần chưa thuộc M1-A07.

## 3. Lệnh kiểm chứng

- `godot --headless --path game --script res://tests/run_ui_flow_tests.gd` (godot_ui_flow).
- `python GDD/tools/validate_levels.py game/data/campaign_m1.json`.

## 4. Rủi ro và trọng tâm review

Đây là flow shell để khóa trải nghiệm MVP; dữ liệu save, Hint, tutorial và thao tác puzzle thực tế sẽ được nối ở M1-A08. Device accessibility/performance chưa được tuyên bố pass từ headless test.
