# M1-A08: MVP runtime integration

## 1. Mục tiêu và bối cảnh

Nối UI flow shell với campaign M1 và các module runtime đã hoàn thành: LevelLoader, InteractionSession/PuzzleCore, GestureEngine, SaveRepository, HintEngine và TutorialController. Mục tiêu là vertical slice có thể chạy từ Home, chơi level thật, lưu/khôi phục, thắng/thua và chuyển level.

## 2. Tiêu chí nghiệm thu

- [ ] Runtime load đúng `campaign_m1.json`, khởi động ở level hiện tại và tạo session đúng puzzle hash.
- [ ] Board dùng level campaign thật, gesture commit đi qua InteractionSession/PuzzleCore và trạng thái session được lưu sau action đã commit.
- [ ] Reload/resume phục hồi level, cells, hearts và Hint count; thắng ghi progress và mở successor; Retry tạo session mới cùng level.
- [ ] Hint gọi HintEngine, chỉ tiêu thụ một Hint khi có evidence và không tự đặt X/mèo.
- [ ] TutorialController được nối cho L01 và state tutorial được giữ trong progress runtime.
- [ ] UI flow nhận event thắng/thua từ gameplay thật, không còn nút mô phỏng trong runtime MVP.

## 3. Lệnh kiểm chứng

- `godot --headless --path game --script res://tests/run_mvp_runtime_tests.gd` (godot_mvp_runtime).
- `python GDD/tools/validate_levels.py game/data/campaign_m1.json` (m1_campaign_validator).

## 4. Rủi ro và trọng tâm review

Save runtime dùng thư mục user data cô lập trong test; device performance, safe-area đo thực tế, asset cuối và M1-GATE vẫn chưa thuộc package này. Không thay đổi luật gameplay hoặc schema canonical.
