## QA

- `MvpRuntime` load campaign M1 theo order `L01` → `L04`, tạo `GestureEngine` thật và đưa level campaign vào `BoardScreen`.
- Session commit được lưu bằng `SaveRepository`; runtime mới khôi phục cells, hearts, mistake count và Hint count theo puzzle hash.
- Thắng L01 ghi result/progress, chọn successor L02 và xoá active session; level kế tiếp dùng board size đúng.
- Hint gọi `HintEngine`, chỉ consume khi có evidence và không tự đặt cat.
- TutorialController được khởi tạo cho L01; tutorial state được ghi vào progress và khôi phục cùng runtime.
- Bootstrap không còn dùng nút thắng/thua mô phỏng; Puzzle route mở `BoardScreen` thật với campaign data.
- Board có Undo, Hint, Restart và Home; Home lưu session hiện tại trước khi quay về flow.

## Remaining risks

- Tutorial runtime đã có state/action API và được lưu trong progress; wiring chi tiết từng gesture vào từng milestone vẫn cần playtest thực tế và có thể tiếp tục tinh chỉnh ở package UX/tutorial tiếp theo.
- Save runtime dùng user data thật khi chạy game; test dùng thư mục cô lập. Chưa có migration cho schema tương lai.
- Headless pass không thay thế device QA về safe area, accessibility, touch target và performance Android/iPhone; M0-A03/M1-GATE vẫn còn mở.
- Asset cuối, âm thanh, rung, settings persistence và M2 content chưa thuộc package này.
- Không thay đổi GDD, governance, luật gameplay hoặc schema canonical.
