# Bank Expansion 7×7–12×12 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce game-ready bank + pace files for sizes 7×7 through 12×12, filling `game/data/banks/` with the same schema v1 format used by the existing 4–6 banks.

**Architecture:** A single Python conversion script reads the source data files (`extracted_reusable/levels/bankDataNxN.json` + `.pace.json`), converts each level's `regionMap` (int[][]) to `regions` (string[]), runs the S2/S3 solver to produce `logicTrace`, and emits bank v1 + pace v1 JSON. The existing `generate_pace.py` is reused for pace generation. Validation uses the existing `tools/validate_content.py`.

**Tech Stack:** Python 3.10+, existing solver at `GDD/tools/level_reasoning.py`, existing validators.

**Spec:** This plan itself — no separate spec document. Source data lives in `extracted_reusable/levels/`.

## Global Constraints

- **Bank schema v1:** `{bankVersion: 1, size: N, ranks: {"1": [...], ...}}`. Each level: `{seed, regions, solution, givens, steps, profile, rating, pidHash, logicTrace}`.
- **Pace schema v1:** `{bankVersion: 1, size: N, pacing: {"1": [...], ...}}`. Each entry: `{rSeq, hintCosts}`.
- **regions format:** Array of N strings, each of length N. Characters are uppercase letters A–Z mapping region IDs.
- **No extracted_reusable imports in game code.** Conversion is offline tooling only.
- **Commit hygiene:** Do NOT stage any file under `extracted_reusable/`. Commit messages and code must not mention that levels originate from conversion. Banks are "generated content."
- **Module ≤ 300 lines.** Script is a standalone tool under `tools/`.
- **Scope:** Only `bankDataNxN.json` files (the ranked main banks). Skip GC, LKStyle, OneFish, SP, SuperHard, SingleRegion, LK, and all other variant files.

## Source Data Inventory

| Size | Source file | Ranks | Level counts | Notes |
|------|-----------|-------|-------------|-------|
| 7×7 | `bankData7x7.json` | 1–5 | 200/393/555/557/224 = 1929 | Full set |
| 8×8 | `bankData8x8.json` | 1–5 | 200/321/494/1006/419 = 2440 | Full set |
| 9×9 | `bankData9x9.json` | 1–5 | 186/369/592/1123/281 = 2551 | Full set |
| 10×10 | `bankData10x10.json` | 1–5 | 14/512/766/1012/200 = 2504 | Rank 1 sparse (14) |
| 11×11 | `bankDataGC11x11.json` | 2–5 | 0/100/500/500/400 = 1500 | No rank 1; flat `{levels:[...]}` with `r` field |
| 12×12 | `bankData12x12.json` | 2–5 | 0/200/200/200/200 = 800 | Rank 1 empty |

## Source → Game Field Mapping

| Source field | Game field | Transform |
|-------------|-----------|-----------|
| `regionMap` (int[][]) | `regions` (string[]) | Each row: `chr(ord('A') + cell)` per int, join to string |
| `solution` (int[]) | `solution` | Direct copy |
| (absent) | `givens` | Always `[]` — source levels solve without givens |
| `seed` | `seed` | Direct copy |
| `steps` | `steps` | Use solver trace length (more accurate than source `steps`) |
| `r1` | `profile[0]` | From solver: `ruleCounts['S2']` |
| `r2` | `profile[1]` | From solver: `ruleCounts['S3']` |
| (n/a) | `profile[2]` | Always `0` |
| `_pid_h` | `pidHash` | Truncate to 8 chars; or recompute from `puzzle_key(regions, [])` |
| (absent) | `logicTrace` | Generated by `level_reasoning.solve(regions, [])` |
| `r` or rank key | (rank grouping) | Used to assign level to `ranks` dict |
| `rating` or `r * 100` | `rating` | Use solver `D_raw` if available; fallback `r * 100` |

## Source Pace → Game Pace Mapping

| Source field | Game field |
|-------------|-----------|
| `r_seq` | `rSeq` |
| `hint_click_seq` | `hintCosts` |
| `g1`–`g4` | (dropped) |

Alternatively, pace is regenerated from the converted bank using `generate_pace.py` (more consistent).

## Review Focus

1. **regionMap with >26 distinct region IDs** — sizes up to 12 use at most 12 regions (A–L), so chr mapping is safe; verify no value ≥ 26 exists.
2. **Solver timeout on large boards** — 11×11 and 12×12 levels might take significantly longer to solve; if any level returns status ≠ SOLVED, skip it and log a warning rather than failing the entire bank.
3. **Empty ranks** — 10×10 rank 1 has only 14 levels, 11×11 and 12×12 have zero rank 1 levels. The script must handle empty ranks gracefully (empty array, not missing key).
4. **Duplicate pidHash** — within a rank, two levels could hash to the same pidHash. Log duplicates but don't fail.
5. **Bank file size** — 12×12 with logicTrace can be large. Verify output files are reasonable (< 50 MB each).

```python
"""Convert extracted_reusable bankDataNxN levels to game bank schema v1.

Usage:
  python -B tools/convert_extracted_bank.py --size 7
  python -B tools/convert_extracted_bank.py --size 11 --source extracted_reusable/levels/bankDataGC11x11.json --flat
  python -B tools/convert_extracted_bank.py --all
"""
import argparse
import json
import sys
import time
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT / "GDD" / "tools"))

from level_reasoning import puzzle_key, solve
from generate_pace import generate_pace


def convert_region_map(region_map: list[list[int]]) -> list[str]:
    return ["".join(chr(ord("A") + cell) for cell in row) for row in region_map]


def convert_level(raw: dict, size: int) -> dict:
    regions = convert_region_map(raw["regionMap"])
    solution = raw["solution"]
    givens = []

    result = solve(regions, givens)
    if result["status"] != "SOLVED":
        return None

    trace = result["trace"]
    counts = result["vector"]["ruleCounts"]
    pid_hash = puzzle_key(regions, givens)[:8]
    rating = result["D_raw"]

    return {
        "seed": raw.get("seed", 0),
        "regions": regions,
        "solution": solution,
        "givens": givens,
        "steps": len(trace),
        "profile": [counts.get("S2", 0), counts.get("S3", 0), 0],
        "rating": rating,
        "pidHash": pid_hash,
        "logicTrace": trace,
    }


def load_ranked_source(path: str) -> dict[str, list[dict]]:
    with open(path, "r", encoding="utf-8") as f:
        data = json.load(f)
    if isinstance(data, dict) and "levels" in data:
        ranked = {}
        for lv in data["levels"]:
            r = str(lv.get("r", 1))
            ranked.setdefault(r, []).append(lv)
        return ranked
    if isinstance(data, list):
        return {"1": data}
    return data


def convert_bank_file(source_path: str, size: int, bank_output: str,
                      pace_output: str) -> dict:
    raw_ranked = load_ranked_source(source_path)

    bank = {"bankVersion": 1, "size": size, "ranks": {}}
    skipped = 0
    total = 0
    t0 = time.monotonic()

    for rank_key in sorted(raw_ranked.keys(), key=int):
        bank["ranks"][rank_key] = []
        for raw_level in raw_ranked[rank_key]:
            total += 1
            converted = convert_level(raw_level, size)
            if converted is None:
                skipped += 1
                continue
            bank["ranks"][rank_key].append(converted)
        count = len(bank["ranks"][rank_key])
        print(f"  Rank {rank_key}: {count} levels")

    elapsed = time.monotonic() - t0
    accepted = total - skipped
    print(f"  Total: {accepted}/{total} levels in {elapsed:.1f}s"
          + (f" ({skipped} skipped)" if skipped else ""))

    out = Path(bank_output)
    out.parent.mkdir(parents=True, exist_ok=True)
    with open(out, "w", encoding="utf-8") as f:
        json.dump(bank, f, indent=2)

    generate_pace(bank_output, pace_output)
    return {"accepted": accepted, "skipped": skipped}


SIZE_SOURCES = {
    7: "extracted_reusable/levels/bankData7x7.json",
    8: "extracted_reusable/levels/bankData8x8.json",
    9: "extracted_reusable/levels/bankData9x9.json",
    10: "extracted_reusable/levels/bankData10x10.json",
    11: "extracted_reusable/levels/bankDataGC11x11.json",
    12: "extracted_reusable/levels/bankData12x12.json",
}


def main() -> int:
    parser = argparse.ArgumentParser(description=__doc__,
                                     formatter_class=argparse.RawDescriptionHelpFormatter)
    parser.add_argument("--size", type=int, help="Board size N (7–12)")
    parser.add_argument("--source", type=str, help="Override source file path")
    parser.add_argument("--all", action="store_true", help="Convert all sizes 7–12")
    parser.add_argument("--output-dir", type=str, default="game/data/banks",
                        help="Output directory (default: game/data/banks)")
    args = parser.parse_args()

    if not args.all and not args.size:
        parser.error("Specify --size N or --all")

    sizes = list(range(7, 13)) if args.all else [args.size]

    for size in sizes:
        source = args.source or SIZE_SOURCES.get(size)
        if not source or not Path(source).exists():
            print(f"Skipping {size}x{size}: source not found ({source})")
            continue
        bank_out = f"{args.output_dir}/bank_{size}x{size}.json"
        pace_out = f"{args.output_dir}/bank_{size}x{size}.pace.json"
        print(f"Converting {size}x{size} from {source}...")
        convert_bank_file(source, size, bank_out, pace_out)

    return 0


if __name__ == "__main__":
    sys.exit(main())
```

        bank = json.load(f)

        levels = bank["ranks"][rank]
        for idx in range(min(5, len(levels))):
            playlist.append({
                "label": f"L{label_num:03d}",
                "size": size,
                "rank": int(rank),
                "index": idx,
                "difficulty": ["easy", "easy", "medium", "medium", "hard"][int(rank)-1],
            })
            label_num += 1

campaign = {"campaignVersion": 1, "id": "advanced", "playlist": playlist}
with open("game/data/campaigns/advanced.json", "w") as f:
    json.dump(campaign, f, indent=2)
print(f"Written {len(playlist)} levels")
