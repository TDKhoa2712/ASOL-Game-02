# Settings buttons

9 PNG RGBA 192×192, cắt trực tiếp từ ảnh nguồn do chủ dự án cung cấp.
Nền bên ngoài viền tròn đã chuyển thành alpha trong suốt; giữ màu và chi tiết bên trong ảnh gốc. Không phóng lớn ảnh nguồn.

| File | Biểu tượng / chức năng |
|---|---|
| `button_audio_on.png` | Bật âm thanh |
| `button_audio_off.png` | Tắt âm thanh |
| `button_music_on.png` | Bật nhạc |
| `button_music_off.png` | Tắt nhạc |
| `button_haptic.png` | Rung thiết bị |
| `button_reduced_motion.png` | Gió/lá — giảm chuyển động |
| `button_large_text.png` | Cỡ chữ lớn |
| `button_colorblind.png` | Hỗ trợ phân biệt màu |
| `button_undo_x.png` | Hoàn tác X |

Trong Godot dùng đường dẫn `res://assets/ui/settings/<tên file>`.
`extraction.json` ghi tọa độ cắt và số pixel alpha để đối chiếu với ảnh nguồn.
